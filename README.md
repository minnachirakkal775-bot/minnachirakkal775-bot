## 🧠 Alzheimer's Disease Detection Using Hippocampus Segmentation with U-Net

**Deep Learning | Medical Image Analysis | Computer Vision | Mobile AI**

A deep learning-based project that uses brain MRI images to identify and segment the hippocampus, a brain region associated with memory and learning.

The system leverages a **U-Net architecture** to perform hippocampal segmentation and analyze its structure, supporting research into Alzheimer's disease.

The project aims to integrate the trained AI model into a standalone Android application, making MRI analysis results more accessible through a mobile interface.

### Key Features

- 🧠 Hippocampus segmentation using a U-Net deep learning model.
- 🩻 Processing and analysis of brain MRI images.
- 🔬 DICOM-to-NIfTI conversion for medical image processing.
- 📊 Visualization of MRI scans and segmentation results.
- ⚙️ FastAPI backend for communication between the AI model and mobile application.
- 📱 Flutter-based Android application for accessing analysis results.
- 🗄️ MySQL database integration.

## ⚖️ LawLens – Citation-Grounded Legal Information Assistant

**Artificial Intelligence | LegalTech | NLP | Semantic Retrieval | Full Stack Development**

LawLens is an India-focused legal information assistant built around the **Bharatiya Nyaya Sanhita, 2023 (BNS)**.

The system provides objective legal information grounded in verified statutory text, using an architecture that combines deterministic database tools, semantic retrieval, citation verification, and large language models.

Its core architectural principle is:

> **"The LLM handles language. Tools handle facts, math, and decisions."**

LawLens processes 358 statutory sections and is designed to provide reliable, citation-grounded responses while avoiding unsupported legal claims.

It does not provide personalized legal advice, case predictions, or attorney-client representation.

### Key Features

- ⚖️ Legal information retrieval grounded in the Bharatiya Nyaya Sanhita, 2023.
- 🔍 Semantic search using precomputed vector embeddings and cosine similarity.
- 🗄️ Deterministic MySQL lookups for direct statutory section queries.
- 🛡️ Guardrails for unsupported statutes, out-of-range sections, and evasion requests.
- 📚 Citation validation against verified statutory text.
- 🤖 Grounded response generation using Groq-hosted `openai/gpt-oss-20b`.
- 🔄 Fallback to verified statutory text when the LLM is unavailable.
- 💬 Conversation context management and message persistence.
- ✅ Pydantic-based response validation.
- 🌐 React frontend with Django REST API backend.
